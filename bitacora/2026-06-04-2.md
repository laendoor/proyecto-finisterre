## Decisiones tomadas

- **RSC wire format en Network tab**: hardcodeado en Next.js 16 (`text/x-component`, sin charset).
  No hay config que lo cambie. Es el protocolo RSC para navegaciones client-side. El Preview tab
  muestra lo mismo. Herramienta adecuada: `rscexplorer.dev` para inspeccionar el árbol RSC.
- **Sign-out via Route Handler**: GET `/api/auth/signout` en lugar de Server Action `logout()`.
  Produce HTTP redirect nativo → la navegación a /login es full-page → HTML en Preview tab.
- **ASCII en error messages del backend**: evita mojibake en RSC stream (ya que Next.js no setea
  charset en el Content-Type). No es un bug del backend — el browser interpreta el stream como
  Latin-1 por el MIME type sin charset.
