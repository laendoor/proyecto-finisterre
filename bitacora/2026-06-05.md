## Decisiones tomadas

- **Route Handlers sobre Server Actions para auth**: los Server Actions en Next.js 16
  native server responden siempre con RSC wire format (`text/x-component`, sin charset).
  No hay configuración que lo cambie. Route Handlers producen HTTP puro → JSON limpio.
- **`source.organizeImports` sin sufijo**: tanto Biome 3.6.1 como Ruff 2026.x con native
  server registran el code action con el ID genérico del LSP, no el vendor-specific.
- **MailService como módulo independiente**: desacopla el proveedor de email del servicio
  de auth. Un cambio de Resend a SES o mock afecta un solo archivo.
- **Refactor de cookies para ticket #7**: los nombres y opciones de cookies se usan en
  3+ lugares (login, signout, proxy). Extraer a `ui/src/lib/cookies.ts` en ticket #7
  antes de agregar la lógica de invitaciones.
