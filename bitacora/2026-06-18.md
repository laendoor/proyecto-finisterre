## Decisiones tomadas

- `signout` no usa `apiHandler` — GET síncrono sin código de error que centralizar.
- Para errores 500, se hace `throw new Error()` (sin mensaje) y el wrapper retorna `UNEXPECTED_ERROR` — callers no necesitan saber el texto del mensaje genérico.
- Para 422 en register: si `body.detail` no es array, se usa `body.detail` directamente como mensaje (antes era `UNEXPECTED_ERROR` con status 422; cambio mínimo, caso improbable).
- El `source.organizeImports.biome` en VS Code settings era un no-op para Biome (la extensión usa `source.organizeImports` sin sufijo), pero disparaba el de TypeScript de alguna forma. La solución fue usar el kind correcto (`source.organizeImports`) para que Biome pise último.
- Biome `organizeImports.groups` config: la línea en blanco entre grupos no es soportada en 2.4.12 vía config; si se quiere, hay que escribirla manualmente y Biome la elimina al hacer check --write.
