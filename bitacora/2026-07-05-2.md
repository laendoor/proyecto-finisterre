## Decisiones tomadas

- `email` embebido en el access token JWT: evita una llamada al backend para resolver el email del usuario en cada page load. El token va en cookie httpOnly, no es problema de seguridad.
- `decodeJwt` sin verificar firma en el header: el proxy (`proxy.ts`) ya verifica con `jwtVerify` antes de dejar pasar la request. El header es puramente cosmético.
- Links como `<Link>` de `next/link` (no `<a>`): evita full page reload y pérdida de estado del cliente. `Link` funciona en server components.
- Route group `(app)` sin sidebar: el workspace será 3 columnas tipo NotebookLM, el admin vive con header solo.
