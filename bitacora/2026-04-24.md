**Bibliografía:**

- Footnotes del portal UNQ reemplazadas por `\citep{unq2025transparencia}`; footnote de Yegro reemplazada por `\citep{yegro2021}`
- Sección "Referencias bibliográficas" con `\section*` + `\addcontentsline` (unnumbered, aparece en ToC)

**Decisión arquitectónica en exploración:**
- MCP (Model Context Protocol): discutido como arquitectura de integración para Hari
  - **MCP server**: expone datos académicos como tools (`query_sql`, `search_documents`) y recursos
  - **MCP client**: Hari (Claude API + LlamaIndex) consume el MCP server
  - Implicación: Text-to-SQL y RAG pasan de ser "enfoques alternativos" a ser dos tools dentro del mismo servidor MCP — el LLM decide cuál usar
  - Todavía exploración, pero prácticamente seguro que entra en scope
