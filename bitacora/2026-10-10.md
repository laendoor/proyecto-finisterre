# Bitácora — 2026-10-10

## Ticket #41 — Log viewer Dozzle (PR #77, hotfix PR #79, release v0.3.0)

Flujo aika completo: start-ticket (discuss) → implement en 3 fases con frenos
sensibles → PR → self-review (doble agente) → review-fix (5/5) → merge →
release → close.

- **Decisión:** Dozzle v11 (`amir20/dozzle:v11`) tras nginx en `/logs/`
  (`DOZZLE_BASE`, proxy sin trailing slash, buffering off por SSE). Grafana+Loki
  descartado por peso.
- **Auth:** `simple` con `users.yml` manual en droplet (`generate` + bcrypt,
  `--user-roles none` view-only). Sin `users.yml` Dozzle ni arranca
  (fail-closed verificado con test) — el orden importa por disponibilidad, no
  por exposición.
- **Seguridad:** actions/shell explícitos en `false`, socket `:ro`,
  `limit_req` en el login.
- **Incidente post-deploy:** 503 en `/logs/` — el rate 5r/m rechazaba los
  assets del propio login (visto en `error.log`). Fix: 10r/s + burst 30
  (PR #79), aplicado primero en droplet y sincronizado al repo.
- **Release v0.3.0:** el tag existía de antes apuntando a un commit fuera de
  main (release corrido desde otro branch el 26/09) — se borró (tag + Release)
  y se re-corrió. Smoke prod: `/logs/` → 307 a login → containers visibles.

Mejoras al workflow (misma sesión):
- `aika-ship-ticket` redefinido como pre-merge (push → crear PR → CI; nunca
  mergea) y `aika-close-ticket` como post-merge; lado ld- sin cambios.
- Regla en `AGENTS.md`: PRs siempre vía `/aika-create-pr`.
- `gen-secret` legible por default, `--strict` para especiales.
- Patrón `.envrc.local` (ignorado) para exports personales (`GITHUB_TOKEN`
  para `make release`); `ggpush` como alias de push upstream.
