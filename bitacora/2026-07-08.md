#### Decisiones de arquitectura
- **NamingConvention**: español para **tipos del dominio** (valores del enum `CARRERAS`, métodos `importar_*`), inglés para **infra** (`detect_type`, `GuaraniUploadService`, `GuaraniSheetType` la clase, `ImportResponse` schemas, fields del JSON `type`/`processed`/`skipped`/`results`/`errors`/`file`).
- **Refactor de `AcademikaError`**: `status_code` como class attr + 1 handler genérico. Si en el futuro se agrega un nuevo tipo de error, solo se hereda y se overridea `status_code` — nada más que tocar en `exception_handlers.py`.
- **Pipeline in-memory over tempfile**: para CSVs admin típicos (<10 MiB). El size cap hard-coded funciona como semáforo — si aparece una planilla grande, el import tronará con un `ImportFailure` claro ("archivo demasiado grande (>10 MiB)") que es la señal para reflexionar y branchear a streaming.
- **`_ORDER` con referencias directas a métodos**: en vez de `getattr(self._importer, method_name_string)(paths)`, ahora `await method_fn(self._importer, contents)`. Type-safe (mypy/pyright podrían catchear rename), no hay strings mágicos. La contraparte: `GuaraniImporterService` queda importado en `_ORDER` (lo está).
