### proyecto-finisterre

**Discusión arquitectónica:**
- Hari es principalmente un chatbot con consulta directa al LLM — esa es la capacidad base (Fase 3)
- Hari también actúa como MCP client para conectarse al servidor propio y a servidores externos (Google Drive, etc.)

- Text-to-SQL se implementa en dos variantes: nativo en Hari (Fase 3) y como herramienta del MCP server (Fase 4) — con mecanismo de switching para comparar en Fase 6
- RAG+pgvector ídem: variante nativa en Hari y como herramienta MCP server (Fase 5)
- Modelo de lenguaje: Claude API en desarrollo, pero arquitectura swappable — se evaluará factibilidad de modelo abierto (Llama/Mistral vía Ollama) para producción en UNQ
