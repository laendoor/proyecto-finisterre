### academika

- **`tools/anon_guarani.py`** creado — script de anonimización de planillas SIU Guaraní:
  - Chequeo temprano de args (falla rápido sin cargar nada si falta el archivo)
  - Chequeo de versión mínima Python (3.11+)
  - Chequeo de dependencias con mensaje de `pip install` para el usuario final
  - Soporte CSV (auto-detección de separador `;` o `,`) y Excel (.xlsx/.xls)
  - 6 estrategias de ofuscación, todas **determinísticas** (mismo input → mismo output siempre):
    - `id` — DNI/legajo: `(n × P + K) mod 10^len` + prefijo 1-9. Output = len(input) + 1 dígitos
    - `nombre` / `apellido` — faker `es_AR` con seed de hash del valor real
    - `email` — faker determinístico
    - `fecha` — year offset desde ref_id (mismo offset para todas las fechas del mismo estudiante), ajuste ±3 días para preservar día de semana
    - `texto` — lorem ipsum determinístico (catch-all)
  - Flujo interactivo con InquirerPy: checkbox de columnas → estrategia por columna → ref_id para fechas → preview → confirmar
  - Output: archivo con sufijo `_anon` en el mismo directorio

- **`pyproject.toml` + `uv.lock` + `.python-version`**: proyecto uv inicializado con `uv init && uv add`
- **`pip.conf`** configurado: `break-system-packages = true` + `user = true` para installs globales desde Homebrew Python

## Decisiones tomadas

- **uv como stack de Python**: reemplaza pyenv + pip + virtualenv. Para proyectos: `uv run`. Para scripts ad-hoc o del usuario final: `pip install` (user-space)
- **Split Python global / proyecto**: `python` global = Homebrew 3.14 (flexible, para scripts random). Proyectos uv usan su propio venv 3.13
- **pip siempre en user-space**: `~/.config/pip/pip.conf` con `user = true` + `break-system-packages = true` — evita romper Homebrew sin sacrificar usabilidad
