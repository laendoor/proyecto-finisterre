### academika

**Ticket #1 — Scaffolding completado** (PR #14, branch `task/monorepo-scaffold-1`):

- **Limpieza root:** eliminados `pyproject.toml`, `uv.lock`, `.python-version` y `main.py` del root.
  uv vive ahora exclusivamente dentro de `api/`.
- **`api/` — FastAPI skeleton:**
  - `pyproject.toml` con uv: `fastapi[standard]`, `uvicorn`, `pydantic-settings` en prod;
    `pytest`, `pytest-asyncio`, `httpx`, `ruff` en dev.
  - Ruff configurado con reglas E, F, I, UP, N, B, S. S105/S106 ignorados globalmente
    (hardcoded passwords — demasiado ruido). S101 ignorado en `tests/**`. B008 resuelto con
    `extend-immutable-calls` para `Depends`, `Security`, `Query`, `Header`, etc.
  - `app/main.py` registra routers; `app/routers/health.py` tiene `GET /health → {"status":"ok"}`.
  - Tests en `tests/unit/` y `tests/integration/`. El test de health usa `httpx.AsyncClient` +
    `ASGITransport` (sin levantar servidor real).
- **`ui/` — Next.js skeleton:**
  - Next.js 16 + React 19 + TypeScript + Tailwind CSS + App Router + `src/` dir.
  - ESLint removido; Biome instalado con migración automática (`biome migrate eslint`). Config
    limpia: formatter con spaces/2, CSS parser con Tailwind habilitado, linter recommended + Next.js
    - a11y rules.
  - Scripts: `npm run lint` (biome check) + `npm run format` (biome format --write).
- **Infra:**
  - `api/Dockerfile` y `ui/Dockerfile` para dev (hot reload via volume mounts en compose).
  - `docker-compose.dev.yml` en root: api + ui + postgres:16 + volumen `pg_data`.
  - `.env.example` con `DATABASE_URL`, `SECRET_KEY`, `NEXT_PUBLIC_API_URL`.
  - `.gitignore` actualizado: `.env`, `ui/node_modules/`, `ui/.next/`.
- **CI — `.github/workflows/ci.yml`:** dos jobs paralelos: `backend` (ruff + pytest via
  `astral-sh/setup-uv@v5`) y `frontend` (biome + next build via `actions/setup-node@v4` con Node 24).
- **Makefile** adaptado de Turner: `install`, `docker-dev`, `db-start/stop`, `dev-api`, `dev-ui`,
  `check`, `format`, `test`, `test-integration` (placeholder hasta ticket #2), `clean`.

## Decisiones tomadas

- **uv solo en `api/`**: root limpio. `tools/` usa Python del SO directamente.
- **Biome reemplaza ESLint completamente** en `ui/`. Migración automática vía `biome migrate eslint`.
- **Tailwind incluido desde el inicio** en `ui/` (shadcn/ui lo requiere en Fase 3).
- **Ruff N+B+S**: naming conventions, bugbear y bandit. S105/S106 silenciados, S101 excluido en tests.
- **`extend-immutable-calls` para FastAPI**: `Depends`, `Security`, `Query`, `Header`, `Cookie`,
  `Body`, `Form`, `File` — evita falsos positivos de B008.
- **Self-review es manual** (opción A): se corre después de que el CI pasa, no automatizado en GitHub.
  La opción B (Claude como reviewer en GitHub via Action) se descartó para proyecto unipersonal.
- **PR #14 mergeado sin cambios**: findings del self-review son menores y se resuelven en tickets
  futuros donde el código afectado tenga más contexto.
