## Decisiones tomadas

- **pgAdmin vs Docker**: la DB de dev es el contenedor Docker. pgAdmin del usuario estaba
  apuntando al Postgres 13 local de Homebrew (instalación residual). Para insertar usuarios de
  prueba hay que usar `docker exec ... psql` o el MCP, no pgAdmin.
- **Sin `--reload` en el debugger**: `uvicorn --reload` genera procesos hijo que no están
  attached al debugger. La config de debug corre sin reload.
- **MCP a nivel workspace** (`seminario/.mcp.json`): el MCP se configuró a nivel del workspace
  raíz, no de `academika/`, porque Claude Code se lanza desde `seminario/`.
